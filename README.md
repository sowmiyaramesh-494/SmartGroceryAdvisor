# Smart Grocery Advisor

## Project Description

Smart Grocery Advisor is a web-based application developed using Flask and MySQL. The system helps users compare grocery prices across different stores and recommends the best store based on the lowest price and product quality.

---

## Features

- User Registration
- User Login
- Admin Dashboard
- Store Management
- Product Management
- Product Price Management
- Quality Rating Management
- Price Comparison
- Best Store Recommendation
